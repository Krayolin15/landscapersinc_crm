# Source files

The three documents every figure in this system came from. They are kept here so
the import can be re-run and checked at any time.

| File | What it is |
|---|---|
| `Landscapers_Inc_CRM.xlsx` | the original CRM — sheets `CRM MAINTENANCE` (56 rows) and `CRM ADHOC` (6 rows) |
| `LSI_INCOME_STATEMENT.xlsx` | management accounts — `Costing`, `Jan`…`Sep`, `Adhoc ` (note the trailing space) |
| `Bank_account_confirmation_letter.pdf` | Standard Bank, 11 August 2026 — the source of the banking details on every invoice |

`docs/DATA_MAPPING.md` records exactly which cell became which column.
Nothing in these files is modified by the application.
