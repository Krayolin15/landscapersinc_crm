The data folder

Both folders here are private company data, and both come filled in the zip:

  • data/seed/: the company records, one JavaScript file per record type plus manifest.js. The app loads them on its first start (local mode). See the data pack.
  • data/vault/: the 253 original documents, filed as <shared drive>/<folder>/<file>. The app opens each document straight from here. Every file matches its record's SHA-256, so a document can never be attached to the wrong record.

Never upload data/seed/ or data/vault/ to a website or commit them to git (.gitignore already excludes them). In Supabase mode the records are loaded once with step 06 from Admin → Go live, the documents are uploaded to Storage with node tools/upload-vault.js, and these folders stay off the website. See the README.
