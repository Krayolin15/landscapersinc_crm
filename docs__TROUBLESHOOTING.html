Troubleshooting

The app does not start

What you seeFix
A blank page, or the splash stays at Waking up the garden…The folder is incomplete or was opened inside the zip. Unzip the whole zip (right-click → Extract All…) to a short place such as C:\LSI, then double-click index.html inside the landscapers-hq folder, next to the js, css and data folders
The company data is missingLocal mode needs the company records in data/seed/, exactly as they come in the zip. Unzip the zip again. (Supabase mode never needs this folder)
The app's files are incompleteA file under js/ is missing. Unzip the whole zip again
Supabase library failed to loadvendor__supabase.min.js is missing from the upload. Upload the whole vendor/ folder
Anything elseReload once. If it repeats, open the browser console (F12) and send the red error text to your administrator

Signing in

  • Forgot password: in Supabase mode, use Forgot password on the sign-in screen, or ask an admin (Admin → Users → Reset). In local mode, an admin resets it under Admin → Users, or, on the computer itself, open reset-password.html in the app folder, choose your name and set a new password (same browser as the app; close any open tab of the app first).
  • "This account is suspended": an admin must reactivate it.
  • The reset link opens the wrong site: set the Site URL and Redirect URLs in Supabase (Authentication → URL Configuration) to the live address.
  • Signed in, but the lists are empty (Supabase): the login is not linked to a staff profile. Run step 08 from Admin → Go live for imported staff, or add the person from Admin → Users.

Someone can't see something

This is usually the permissions working as intended (SECURITY.html). Check the person's role under Admin → Users, and whether the item is:

  • in the FINANCE or HR drive;
  • marked confidential;
  • an HR or incident form response;
  • a restricted spreadsheet.

Emails are not sending

  • Mail shows Email is not configured: set the RESEND_API_KEY and MAIL_FROM secrets (SETUP-SUPABASE.html).
  • Resend rejects the sender: the MAIL_FROM domain is not verified in Resend.
  • Agent reminders stay queued: the same two secrets are missing for agent-run.
  • WhatsApp reminders wait in Autonomous Core → Approvals until someone taps send, unless the Twilio secrets are set.

The 05:00 / 05:30 agent did not run

  1. In the Supabase SQL editor:

    select jobname, status, start_time, return_message from cron.job_run_details order by start_time desc limit 20;
  2. no agent_cron_secret in Vault: create the Vault secret (step 7 of SETUP-SUPABASE.html).
  3. HTTP 401 from agent-run: the Vault secret and the CRON_SECRET function secret differ, or the function was deployed with the login check on. Deploy it again with node tools__deploy-functions.js --only agent-run --project-ref <your project ref>.
  4. HTTP 404: the project ref in step 07 was not filled in. In Admin → Go live, type your project ref at step 07 and run that step again.

While someone has the app open, the in-browser agent also runs the same jobs. Autonomous Core shows which agent ran each job.

Phones show an old version

App code loads fresh on every start, so close the app completely and open it again. If it still looks old: browser settings → site settings → clear storage for the app's address, then open it again. Local-mode data lives in that storage, so export a backup first.

Photos or documents do not open

  • A yellow message says the app folder sits too deep, or documents say not found although they are in data/vault/: Windows cannot open files whose full path is longer than 260 characters. Move the landscapers-hq folder to a short place such as C:\LSI and open index.html from there.
  • Document not found: the record points to an original company document whose file is not where the app looks. Local mode: the data/vault/ folder is missing or incomplete; unzip the zip again. Supabase: the documents were not uploaded yet; run node tools__upload-vault.js (SETUP-SUPABASE.html).
  • Its contents cannot be read while the app is opened from the folder: a feature (Sheets import, a slide PDF, an attachment) needs the document's contents. Go to Drive → Load original documents once and choose the data/vault folder, or run the app through the local web server (README).
  • Load original documents says files differ from their records: those files were changed since the zip was made, so they were left out. Unzip the original zip again to get the unchanged files.
  • You do not have access to the attachment: the file is confidential or in a restricted drive.

Spreadsheets

  • A formula shows #REF!: it pointed at rows, columns or a tab that was deleted.
  • #NAME?: an unknown function name. Type = and the first letters of a function to see matching names.
  • Two people edited the same sheet: both sets of changes are kept. When you both changed the same cell, the last save wins, and the app says when someone else's edit arrives.

For administrators and developers

npm test
npm run test:sql
npm run check
npm run test:browser
  • npm test runs the unit tests.
  • npm run test:sql checks the go-live SQL and every access rule in a real Postgres.
  • npm run check loads every module to find broken imports, and says when js__app.bundle.js is out of date: after changing anything in js/, run npm run build, or a double-clicked index.html keeps running the old code.
  • npm run test:browser opens the app in headless Chrome or Edge, both double-clicked and served.
  • Admin → System also has a built-in self-test.
